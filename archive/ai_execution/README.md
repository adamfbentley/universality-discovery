# AI Execution Archive

This directory contains historical prompts, handoff notes, simulated reviews,
and AI-oriented audit records used during development.

The material is retained to disclose how AI systems contributed to
implementation and review. It is not scientific evidence and should not be
cited as independent validation. Current claims are governed by
`ml_paper/CLAIMS_REGISTER.md`, while the division of labour and validation
status are documented in `PROVENANCE.md`.
